Understanding the Difference Between Box-Sizing Values

Default Box-Sizing

Default Box

The default box-sizing value is content-box. Width and padding are added together, so the total size becomes larger than the specified width.

Border-Box

Border Box

With border-box, the specified width includes both padding and border. Therefore, the total size remains within the given width.
