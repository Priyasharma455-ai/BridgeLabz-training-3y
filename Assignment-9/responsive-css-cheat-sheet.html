Responsive CSS Cheat Sheet

Filters

Used to apply visual effects to elements.

filter: grayscale(100%);

Media Queries

Used to apply CSS rules according to screen size.

@media (max-width: 700px)

Responsive Design

Makes a website adapt to different screen sizes.

width: 100%;

Typography

Controls the appearance and size of text.

font-size: clamp(1rem, 2vw, 1.5rem);
