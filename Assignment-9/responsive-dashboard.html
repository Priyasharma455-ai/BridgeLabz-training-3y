CSS Topics

Filters

CSS filters are used to apply visual effects such as grayscale, blur and brightness.

filter: grayscale(100%);

Typography

Responsive typography allows text to adjust according to different screen sizes.

font-size: clamp(1rem, 2vw, 2rem);

Media Queries

Media queries apply different CSS rules based on the screen size.

@media (max-width: 750px)
